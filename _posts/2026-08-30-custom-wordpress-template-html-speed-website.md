Nowadays, you can see a lot of WordPress templates, for example, in TemplateMonster.

Most of them are created with Elementor.

But for long-term projects, I don't prefer to use that type of template. I prefer to use a simple HTML template that can be integrated into WordPress.

This approach has some advantages:

- you just get what you need: you don't get some unnecessary functions from third-party templates; you get exactly the same functionality that you need
- you don't use Elementor or some heavy templates
- your website works really fast

If you want to have a good score in Google Insights, you need to have a really optimized website.

But if you create your website with an HTML template, you don't even need to optimize something in a lot of cases. Because your website will be really lightweight.

Mainly, that HTML template must not be huge to give you a good result. I always choose templates that do not have too many huge images, animations, etc.

I prefer a website with strong functionality to a beautiful picture that doesn't work.

Not so much JavaScript code and CSS make your website easy to execute for a lot of browsers and not-so-strong computers.
