The role of AI is helping us to do our work faster.

Sometimes AI can help you to do your work, but sometimes it can make troubles for you.

Every time, you need to keep in your mind that you need to have the opportunity to control the code written by an AI.

For small projects, that is not so much necessary, but if you make something long-term, you need to understand what is under the hood.

Mainly, how you need to treat it depends on the project.

## Landing Pages, WordPress, Small Projects

For small or not complex projects, AI is more suitable. An AI can now convert even from Figma to HTML (of course, if you make some corrections to the results), make a small online store on WooCommerce, and etc. With that type of project, maintenance is often not so critical. Because that type of project can be created just one time and not touched for a long time. And then, if you need some prototyping of your projects, AI can be a perfect fit.

But still, you need to pay attention to the security issues that AI can create, for example, for your WordPress website.

If you just need a temporary prototype, I mean a working website, but still for testing, you can simply not check what code the AI writes.

But if you need a maintainable project, don't ignore the AI code for a long time and make corrections even for small projects.

## Custom Development: Laravel, Symfony, etc.

And we have another side of AI development for custom projects. Big custom projects need continuous maintenance.

You can't just generate the code for Laravel or Symfony projects and hope that your project will live long.

Every part of AI-generated code needs to be checked and corrected.

But still, what is easier? Check AI code or write that code by yourself?

Mainly, you need to find the balance for you. Basically, huge parts of AI code will be hard to check.

Then you need to give the AI not so much global commands. And try to get the solution to a small part of the issue.

Then you can know how your AI agent thinks and control its behaviour more correctly.
